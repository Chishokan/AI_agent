# knowledge（ナレッジ層）

エージェントが配布計画・実績分析・提案を作るときに参照する Markdown 層。
Obsidian vault としても開ける。**個人情報は書かない**（傾向・属性・集計のみ）。

- `校舎特性/` … 校舎ごとの立地・客層・配布の勘所。`_テンプレート.md` に構成を揃える。
- `過去施策/` … 過去の配布施策の振り返り。1施策1ファイル（`YYYY-MM_校舎_テーマ.md`）。
- `提案テンプレ/` … 提案ドラフトの雛形。`/提案作成` がこれを踏襲する。

数字は `data/distribution.db` と整合させ、出所（期間・DB・既定値か）を併記する。
