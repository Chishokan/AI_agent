# sql/ — 集計クエリ集

`/実績分析` が参照する再利用 SQL。`sqlite3 ./data/distribution.db < ./sql/分析/<file>.sql` で実行する。

## sql/分析/

| ファイル | 内容 |
| --- | --- |
| `01_校舎別反応率.sql` | 校舎別の配布枚数・反応数・体験申込率（期間指定。BETWEEN を書き換え） |
| `02_月別推移.sql` | 月別の配布枚数・反応数・反応率 |
| `03_チャネル別.sql` | 校舎×チャネル（体験申込/問い合わせ/入塾）別の反応数 |
| `04_計画vs実績.sql` | 校舎別の計画→実績枚数と達成率 |
| `05_施策別サマリ.sql` | 施策別の配布枚数・反応数・反応率 |
| `06_在籍数_部門別.sql` | 在籍数の最新スナップショット（部門の粒度はここだけ） |

## 注意

- **反応率は必ず分母（配布枚数）とセット**で出す。
- **配布・反応は校舎単位**で、`division`（部門）列を持たない。部門別に割れるのは `enrollment`（在籍数）のみ。
- 数字が無いセルは「データ無し」。推定で埋めない。
