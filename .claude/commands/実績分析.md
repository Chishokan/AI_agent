# /実績分析

入力: `$ARGUMENTS`

`data/distribution.db` を集計し、配布実績の分析を行う。

## 1. 集計対象の解釈
- 引数が `YYYY-MM` なら期間、校舎名なら校舎で絞り込む。両方あれば両方で絞る。
- 引数が無ければ直近の利用可能な期間を対象にし、その旨を明記する。

## 2. SQL で集計（sqlite3）
`Bash(sqlite3 ./data/distribution.db ...)` で以下を集計する。

- 校舎別・部門別の **配布枚数**（`SUM(distribution.actual_qty)`、無ければ planned_qty）
- チャネル別の **反応数**（`SUM(response.count)`）
- **反応率** = 反応数 / 配布枚数（分母を必ず明示）
- 計画 vs 実績（`planned_qty` → `actual_qty`）の差
- 目標が分かる場合は **目標 → 実績** の差（向きを取り違えない）

集計クエリ例:
```sql
SELECT c.name AS campus,
       SUM(d.actual_qty) AS sheets,
       (SELECT SUM(r.count) FROM response r WHERE r.distribution_id = d.id) AS responses
FROM distribution d
JOIN campus c ON c.id = d.campus_id
WHERE d.date LIKE '2026-04%'
GROUP BY c.name;
```

## 3. 出力
- Excel / Google Sheets に貼れる表（校舎・部門・配布枚数・反応数・反応率・目標差・備考）。
- 反応率の分母（配布枚数）を必ず併記する。
- 該当データが無いセルは「データ無し」と明記し、推定値で埋めない。
- 気づき（伸びた校舎・落ちた校舎・チャネル傾向）を箇条書きで短く添える。
