# /実績分析

入力: `$ARGUMENTS`

`data/distribution.db` を集計し、配布実績の分析を行う。

## 0. 前提（スキーマの粒度）
- **配布実績（distribution）・反応（response）は校舎単位**で、部門（division）の列を持たない。
  → 配布・反応は **校舎 × チャネル × 期間** で集計する。「部門別の配布/反応」は出せない。
- **部門の粒度を持つのは在籍数（enrollment）のみ**。部門の話をするときは在籍数を併記する。

## 1. 集計対象の解釈
- 引数が `YYYY-MM` なら期間、校舎名なら校舎で絞り込む。両方あれば両方で絞る。
- 引数が無ければ直近の利用可能な期間を対象にし、その旨を明記する。

## 2. 集計（sqlite3 + 既製クエリ）
`sql/分析/` に既製クエリがある。`Bash(sqlite3 ./data/distribution.db < ./sql/分析/<file>.sql)` で実行する。
期間・校舎で絞るときは、クエリ内の `BETWEEN` リテラルや `WHERE` を書き換える。

| 観点 | クエリ |
| --- | --- |
| 校舎別 配布枚数・反応数・体験申込率 | `sql/分析/01_校舎別反応率.sql` |
| 月別推移 | `sql/分析/02_月別推移.sql` |
| 校舎×チャネル別 反応数 | `sql/分析/03_チャネル別.sql` |
| 計画→実績 達成率 | `sql/分析/04_計画vs実績.sql` |
| 施策別サマリ | `sql/分析/05_施策別サマリ.sql` |
| 在籍数（部門別）スナップショット | `sql/分析/06_在籍数_部門別.sql` |

目標値が分かる場合は **目標 → 実績** の差を出す（向きを取り違えない。目標と実績は別物）。

## 3. 出力
- Excel / Google Sheets に貼れる表（校舎・チャネル・配布枚数・反応数・反応率・目標差・備考）。
  部門の話を入れるときは在籍数の表を分けて添える。
- **反応率は必ず分母（配布枚数）を併記**する。
- 該当データが無いセルは「データ無し」と明記し、推定値で埋めない。
- 気づき（伸びた校舎・落ちた校舎・チャネル傾向）を箇条書きで短く添える。
