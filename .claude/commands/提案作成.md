# /提案作成

入力: `$ARGUMENTS`

実績分析と提案テンプレをもとに、配布施策の提案ドラフトを作成する。

## 1. テーマ・対象の解釈
- 引数から **対象校舎** と **テーマ**（例: 体験申込の底上げ）を読み取る。
- 曖昧なら、対象校舎・狙うチャネル・時期を確認してから進む。

## 2. 根拠を集める
- `knowledge/提案テンプレ/` の雛形を Read し、構成を踏襲する。
- 対象校舎の `knowledge/校舎特性/<校舎>.md` と `knowledge/過去施策/` を Read する。
- 必要なら `/実績分析` 相当の集計（sqlite3）を行い、現状の反応率・目標差を把握する。
- 配布数の試算が要るときは `haifu-tool` を使う。

## 3. 提案ドラフトの作成
提案テンプレの構成に沿って、以下を含める。
- 現状（実績の要点。反応率は分母を明示）
- 課題（目標 → 実績 のギャップ）
- 施策案（配布場所・時期・枚数・狙うチャネル。校舎特性に紐づける）
- 期待効果（haifu-tool の試算。反応率の出所を明記。実績が無ければ既定値である旨を明示）
- 必要なリソース / リスク

## 4. 出力
- 人がそのまま会議資料に使えるドラフトとして Markdown で出力する。
- 数字の根拠（使った反応率・在籍数・期間）を明記し、作り話で埋めない。
- 確定値ではなく「ドラフト」であること、最終判断は人が行うことを添える。
