# /配布計画

入力: `$ARGUMENTS`

校門配布の配布計画を作成する。手順は以下の通り。

## 1. 入力の解釈
- 第1引数を **校舎名**（駅前校 / 日野校 / 大野校 / 日宇校 / 大島校）として解釈する。
- 第2引数が「目標◯件」なら **target mode**、「在庫◯枚」なら **supply mode**。
  - 解釈が曖昧なら、どちらのモードか・数値の単位を確認してから進む。
- 目標のチャネル（体験申込 / 問い合わせ / 入塾 など）が分かれば控えておく。既定は「体験申込」。

## 2. 前提を揃える（必須）
- 対象校舎の `knowledge/校舎特性/<校舎>.md` を Read して、立地・客層・配布の勘所を把握する。
- 同じ校舎の `knowledge/過去施策/` に関連する振り返りがあれば目を通す。

## 3. haifu-tool で配布数を算出
- **target mode**: `haifu-tool` の `plan_by_target` を呼ぶ。
  - 引数: campus, target_responses, channel（分かれば）, division（指定があれば）。
  - 反応率は DB 実績から自動算出される。`rate_source` が `default`（実績なし）なら、その旨を計画に明記する。
- **supply mode**: `haifu-tool` の `plan_by_supply` を呼ぶ。
  - 引数: total_sheets, campuses（指定があれば、なければ全校舎）, weight_by。

## 4. 校舎特性を踏まえて計画化
- ツールの算出値は出発点。校舎特性（時間帯・配布場所・客層）を踏まえて、配布枚数・場所・タイミングの提案に落とす。
- 反応率は必ず分母（配布枚数）を明示する。目標と実績（=見込み）を取り違えない。

## 5. 成果物の整形
- Excel / Google Sheets に貼れる表形式（校舎・部門・配布枚数・想定反応数・反応率・備考）で出力する。
- 算出根拠（使った反応率とその出所、在籍数）を表の下に注記する。
- DB にデータが無い前提は「データ無し（既定値◯◯を使用）」と明記し、作り話で埋めない。
